# Tic-Tac-Toe WinForms Edition

A robust Windows-based implementation of the classic Tic-Tac-Toe game, featuring a graphical user interface for seamless two-player interaction. The application provides a complete game lifecycle, from player initialization to automated victory condition validation.

## Key Features
* **Automated Win Logic:** Real-time evaluation of eight possible winning combinations across rows, columns, and diagonals, including integrated draw detection.
* **Dynamic Game State Management:** Intelligent turn-tracking system with interactive UI updates, visual player indicators, and green-highlighting for winning sequences.
* **Session Persistence:** Streamlined game reset functionality that reinitializes the board, clears status flags, and prepares the UI for a new match without restarting the application.

## Technical Stack
* **Language:** C#
* **Framework:** .NET Framework 3.5
* **UI Library:** Windows Forms (WinForms)
* **Graphics:** GDI+ (System.Drawing) for custom board rendering and resource-based asset management.
